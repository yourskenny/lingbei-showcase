# 另册 · 浮生十二食辰志

《最后一单》之外的平行版本，依据团队提供的 `stitch_.zip` 设计稿重制。主站仍是根目录的《最后一单》，本册独立挂在 `/shichen/`，不影响主站内容与导航。

线上地址：<https://yourskenny.top/lingbei-showcase/shichen/>

## 这一版是什么

- 主题：市井烟火 · 十二时辰食候
- 形式：宋刻朱墨双色套印风格的单页长卷
- 结构：卷端序引 → 浑天星历（十二辰星盘）→ 古今对勘 → 治世食货 → 卷末长跋
- 交互：点击 / 悬停十二辰，星盘当值时辰点亮，右侧对勘文字随之切换；方向键可在十二辰间移步

## 实现

- 纯静态：`index.html` + `style.css` + `app.js`，无构建、无框架、无外部字体
- 字体使用系统宋体栈（Noto Serif SC / Source Han Serif / Songti SC / SimSun）
- 图片为 WebP，5 张合计约 344 KB，含宽高属性避免版式跳动
- 浑天星盘为内联 SVG，连续旋转动画在 `prefers-reduced-motion` 下停止
- 响应式：1440 / 390 均无横向溢出；窄屏表格自动转为卡片

## 素材与说明

- 5 张图版从 `stitch_.zip` 的 1440 宽导出图（2×）中裁切、去标注后转 WebP
- 文中古籍引文为设计稿中的文学化拟写，页脚已注明“非严格史料原文”
- 若正式提交比赛，建议把生成图版替换为团队自摄或已授权素材，并在主 README 中补充素材来源
